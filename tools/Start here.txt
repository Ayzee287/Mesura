Mesura: set up Windows and restore your environment

1. Copy this whole folder to the PC, not just Mesura.exe, and not to a USB stick you will unplug.
   A good place: %LOCALAPPDATA%\Programs\Mesura

2. Start Mesura.exe from there. Windows SmartScreen may say the app is unrecognised, because the file is not code-signed
   (check the zip's SHA-256 against SHA256SUMS.txt first, then "More info" > "Run anyway"). From an all-users install it asks Windows for administrator
   rights as it starts, so changes to the whole PC work (you can decline, or change the question in Settings); a folder you copied yourself, or a per-user install,
   does not ask, and the window says which changes are skipped. Nothing changes until you confirm an Apply, Install, Undo or
   profile run; each is recorded in Activity, where Windows changes and app settings can be undone.

3. Home is the start page; Optimization is where you choose Mesura Reference or Maximum performance, look at the plan for this PC, then Apply (a window shows everything first).
   Entries that do not apply to this PC (no Radeon, no matching network adapter, no battery, Windows Home...) are listed under "not on this PC" with the reason and are never written.
   Both levels change the settings of a network adapter that matches a preset (Realtek, Intel or Killer); the adapter restarts for a few seconds when a value is written.
   All settings lists every setting by category, with its risk and what is known about it.

4. In Settings, choose the language (English or Russian), and switch on "Show in the Start menu" and, if you like,
   "Start in the tray when I sign in".

To restore your setup on a fresh install: on your set-up PC, Backups > New > This PC's setup, check what the file will
hold, and save it; keep the two files it writes (the setup and its settings file) together, for example on the USB
stick with this folder. On the new PC, Backups > Open a backup..., check the steps, Run, do what "What's left"
lists, then Run again. The App settings tab exports and restores the settings of Steam, Brave, Discord, Vencord and Spotify.

The command line is cli\mesura.exe (run "cli\mesura.exe --help"; cli\example.profile.json is an example profile).
The window, the tray and the command line share one history and, if you edit them, one copy of the catalogs
(Settings > Catalogs > Copy to edit).

Advanced settings (All settings, "Security protections off" and "Less in the background"): memory integrity, virtualization-based
security, the Spectre and Meltdown mitigations, the hypervisor, SmartScreen and the download mark, and some background and cloud functions can be switched off
one by one. No profile applies any of them. Each shows what it costs (anti-cheat may refuse to start, protection against malware is lower, Hyper-V and WSL stop working,
OneDrive stops syncing); none promises a faster PC. Every change is recorded in Activity and can be undone; those that need a restart say so.

If Mesura doesn't start: double-click "Diagnose Mesura.cmd" in this folder. It reads (and changes nothing), then writes
Mesura-diagnostics-<time>.txt to the Desktop; send that file to whoever gave you Mesura. Mesura also keeps a short log of each
start in %LOCALAPPDATA%\Mesura\logs\mesura-startup.log. Keep the whole folder together: Mesura.exe needs the .dll files
beside it. Windows 10 1607 or later, 64-bit, is required.

Before you rely on it: little of this has run on real PCs (README.md, "Limits you should know about"): of the network
presets only the Intel Wi-Fi one has been written on a real adapter, no profile was applied as a whole on a real PC, and the advanced settings and the other 14 network
adapter settings were checked in Windows Sandbox only. Read the plan Optimization shows before you apply it, and use Activity to undo.
