# App icons

Each app's own icon, 96 × 96 PNG, named by its catalog id, shipped inside Mesura so Apps and Setup show it offline
(D031). They identify the apps Mesura installs; they are the vendors' marks, not Mesura's.

Collected on 2026-10-23, then resized with high-quality bicubic scaling, alpha kept:

| Icon | Source |
|---|---|
| brave, discord, git, sevenzip, spotify, steam, vscode | the application's own executable, installed on PC-000 (shell icon at 256 px) |
| chrome | Google's Chrome site: `https://www.google.com/chrome/static/images/favicons/favicon-96x96.png` |
| notepadpp | Notepad++'s repository: `PowerEditor/src/icons/npp.ico` |
| obs | OBS Studio's repository: `frontend/forms/images/obs.png` |
| vencord | Vencord's repository: `browser/icon.png` |
| telegram | Telegram Desktop's repository: `Telegram/Resources/art/icon256.png` (collected on 2026-10-30) |
| regorganizer | ChemTable's site: `apple-touch-icon.png` (the company's mark, resized; collected on 2026-10-30) |
| ayugram | AyuGram Desktop's repository: `Telegram/Resources/art/icon256.png` (collected on 2026-10-30) |

An app without an icon here shows its initial instead. A new app's icon comes from the same kind of source: its own
executable or the vendor's official site or repository, never a third-party icon pack.
