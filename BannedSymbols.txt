// The side-effect boundaries (architecture §2.3, D021), enforced in every production project by
// Microsoft.CodeAnalysis.BannedApiAnalyzers (RS0030, an error under TreatWarningsAsErrors).
// Every change to this file is reviewed.
//
// Each overload is listed by its exact documentation ID. The shorter "M:Type.Method" form, which the
// analyzer's help describes as banning every overload, was tested with version 5.6.0 and banned nothing.
// The IDs were generated with Roslyn's DocumentationCommentId from the .NET 10.0.12 reference assemblies
// and System.Management 10.0.12; regenerate them when either changes.
//
// Each allowed side effect has one owner class that suppresses RS0030 locally with a justification: LocalStore in
// Platform (the diagnostic layer's own files and user-requested exports); SetupStore and WingetRunner in Setup (D021);
// WindowsWriter in Setup (registry, service start types, dism and powercfg; D023); ShellLauncher in App (open a settings
// page or URL, relaunch elevated; D025); NvidiaTools in Setup (start NVCleanstall, run NVIDIA Profile Inspector's export
// and merge import) and LicensingWriter in Setup (install a user's product key, activate, clear the key from the registry
// through WMI; D031).
// Nothing here may be unbanned to make a collector "work", and the diagnostic projects gain no new owner.
